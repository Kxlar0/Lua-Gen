FAQ

                
                

                    
📁 What are these files used for?

                    
These files are used for steamtools to download and manage games. The manifest.json contains metadata and file lists, while the Lua script provides game logic integration.

                


                

                    
💬 Where do I request a game?

                    
Join the official Discord community and ask there. The maintainers are active and respond to requests regularly.

                


                

                    
🔗 Why is there no shortlink?

                    
All files are generated directly on your computer with instant downloads. No external links or redirects needed for a faster, cleaner experience.

                


                

                    
🎮 Can I modify the generated files?

                    
Yes! These are just template files. Feel free to edit the JSON manifest and Lua script to match your specific needs.

                


                

                    
✅ Is this safe?

                    
Absolutely. Everything is processed locally in your browser. No data is sent to external servers. Your App ID is only used to generate the template files.
